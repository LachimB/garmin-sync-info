Privacy Policy

Last updated: 11 November 2026

Garmin Sync is a personal, single-user utility operated by its owner. This policy describes how the utility uses Google Drive and Garmin fitness data. This website is a public description of the utility, not a hosted service.

Data accessed

The utility retrieves Garmin activity and wellness information authorized by its owner. Depending on enabled exports, this can include activity names, types, dates, performance metrics, GPS routes, sleep measurements, heart-rate metrics and other wellness readings.

The utility uses the Google Drive API to create, update and read application-authorized export files in the owner's dedicated Drive account. Google authorization uses the drive.file scope. It does not request general access to all Google Drive content.

Purpose and storage

Data is processed locally on the owner's Mac or Android phone to prepare JSON exports, then uploaded to the owner's dedicated Google Drive account for backup and analysis. The owner determines which measurements are exported and how long the files remain stored.

Credentials and private local state remain on the owner's device and are excluded from exports. The Android app uses Android Keystore-backed encryption for the Garmin API key and filename key, and Google authorization for the selected Drive owner account. The Android app embeds no Google server credentials. App-private data is excluded from ordinary Android backups; encrypted migration bundles and recovery copies must be kept private.

Sharing

No Garmin data is published on this website or sold. Export files are stored with Google Drive, which processes them under its applicable terms and privacy policies. If the owner separately authorizes an AI assistant, such as ChatGPT, to read the dedicated Drive account, the assistant's provider may process the selected data to answer the owner's requests under its applicable terms and settings.

Retention and deletion

Data remains in local files and the owner's Google Drive until the owner deletes it. The owner can revoke the Google OAuth authorization in Google Account settings and remove the local configuration and export files. Revocation does not automatically delete files already uploaded to Drive.

Security

This utility is intended for personal use only. The owner controls the Garmin credentials, Google API configuration, devices, and Google Drive storage. GPS tracks can disclose sensitive locations even if numeric account identifiers are removed.

Website visitors

This static GitHub Pages website does not operate an account system, submit forms, or intentionally set tracking cookies. GitHub may process standard hosting and security logs under its own policies.

Changes

This policy may be updated if the utility's data handling changes. The updated version will appear at this URL.
