Garmin Sync

Garmin Sync is a personal, locally operated tool for exporting fitness and wellness measurements from Garmin Connect and backing up selected JSON files to a dedicated Google Drive account.

What this tool does

The tool runs locally on the owner's Mac or Android phone. Only one device publishes exports at a time. It retrieves Garmin measurements, prepares local exports, and uses Google Drive API authorization to upload those exports to the owner's Google Drive account.

The requested Google Drive permission is limited to files created or opened for this application (drive.file). The tool is not intended for other users.

What this website does not do

This public website is informational only. It does not accept logins, collect Garmin or Google credentials, display workout routes, or host any private activity or health records.

Read the Privacy Policy to learn how the utility handles data and permissions.
